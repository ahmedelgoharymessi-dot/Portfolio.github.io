About Me

Developer,
Builder & Founder.

I'm Ahmed Elgohary, a self-driven web developer based in Riyadh, Saudi Arabia. I build complex, full-stack web platforms and interactive applications with a deep passion for clean code and ambitious ideas.

I founded PhineX Group — a developer community and organization pushing next-generation software for developers and gamers. Under the PhineX umbrella I've shipped: a full community platform, a Discord bot, a multiplayer Arabic social-deduction game, a VSCode-style web editor, an AI math solver, and more.

My core stack is Firebase, JavaScript ES modules, Three.js, Tailwind CSS and HTML/CSS. I also do Roblox game development in Luau.
